# Privora 4.0 RC2 — Prism Release Candidate

Privora is a Debian 13-based commercial desktop distribution by Privora Labs. This release-candidate tree is feature frozen and carries the first-party Prism installer, hardware-aware recommended partitioning, advanced manual storage controls, the Privora Labs boot/splash identity, 27 first-party/meta Debian packages, the production Privora Linux-kernel framework, and the independent PrivoraKernel research track.

The final flashable ISO, destructive installer certification, production Secure Boot trust, and physical hardware certification remain external release gates.
